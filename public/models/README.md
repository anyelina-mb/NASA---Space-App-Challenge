3D bodies used by the Body Scan screen (made in Blender from the two base meshes, cut into 23 named parts):

- `body.glb`: male body
- `body_female.glb`: female body

Each part is a separate object named like `src/data/body-parts.json` (`head`, `chest`, `arm_L`, `knee_R`...).
The Blender source is `assets/bodies.blend`.
